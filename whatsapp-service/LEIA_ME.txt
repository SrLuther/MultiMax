9. ✅ Trata EXCEÇÕES gracefully (nunca trava o sistema)
10. ✅ Encerra GRACIOUSLY (SIGINT, SIGTERM)

🚀 COMO USAR (PASSO A PASSO):

1. Executar schema SQL no banco:
   psql -U multimax -d multimax -f whatsapp-service/schema.sql

2. Iniciar o serviço:
   docker-compose up -d whatsapp-service
   (ou: cd whatsapp-service && node index.js)

3. Escanear QR code no WhatsApp:
   docker logs whatsapp-service | grep -i qr

4. Configurar número de alerta:
   curl -X PUT http://localhost:3001/settings/alert-phone \
     -H "Content-Type: application/json" \
     -d '{"phone": "11987654321"}'

5. Testar envio:
   curl -X POST http://localhost:3001/settings/test-alert-phone

6. Você deve receber mensagem no WhatsApp! ✓

🆘 PROBLEMAS COMUNS:

❌ "WhatsApp não está conectado"
   → Ver logs: docker logs whatsapp-service | grep -i qr
   → Escanear QR code no WhatsApp

❌ "Número de alerta não configurado"
   → Configurar: curl -X PUT http://localhost:3001/settings/alert-phone ...

❌ "Número inválido"
   → Formato: 11987654321 ou +5511987654321
   → Deve ter DDD (2 dígitos) + 8-9 dígitos

❌ "Não recebo heartbeat"
   → Verificar: WhatsApp deve estar conectado
   → Próximo heartbeat em até 6 horas

❌ "Docker events não funciona"
   → Verificar permissão: ls -la /var/run/docker.sock
   → Dar permissão: sudo usermod -aG docker $USER
