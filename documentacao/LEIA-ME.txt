MULTIMAX - SISTEMA DE GESTÃO COMPLETO

DESCRIÇÃO:
MultiMax é um sistema completo de gestão para açougue e negócios similares, incluindo:

📦 GESTÃO DE ESTOQUE E PRODUTOS
- Controle completo de produtos com código, nome, quantidade
- Gestão de preços (custo e venda)
- Controle de validade e lotes
- Estoque mínimo com alertas automáticos
- Localização de produtos e categorização
- Geração de QR codes para produtos

👥 GESTÃO DE COLABORADORES
- Cadastro completo de funcionários
- Controle de jornada de trabalho (horas extras e folgas)
- Sistema de ciclos de pagamento
- Gestão de férias e atestados
- Escalas de trabalho semanais
- Cálculo automático de horas e conversões

🥩 CONTROLE DE CARNES
- Recepção de carnes com controle de peso
- Gestão de fornecedores
- Controle de temperatura e validade
- Relatórios diários e semanais
- Rastreabilidade completa do produto

🍽 RECEITAS E CARDÁPIO
- Sistema completo de receitas
- Gestão de ingredientes e catálogo
- Cálculo automático de custos
- Controle de rendimento e preparo
- Embalagem e tempo de preparo

🧹 CRONOGRAMA DE LIMPEZA
- Gestão de tarefas de limpeza
- Frequência automática de notificações
- Controle de conclusão com fotos
- Checklist de verificação
- Histórico completo de limpezas

📊 RELATÓRIOS E EXPORTAÇÕES
- PDFs personalizáveis para todos os módulos
- Exportação CSV e Excel
- Gráficos e análises de dados
- Relatórios de produtividade
- Histórico completo de operações

🔔 SISTEMA DE NOTIFICAÇÕES
- Alertas de estoque baixo
- Notificações de limpeza
- Avisos de validade próxima
- Sistema de notificações diárias personalizadas
- Controle de leitura de notificações

🏠 ADMINISTRAÇÃO DO SISTEMA
- Gestão de usuários e permissões
- Controle de acesso por níveis (Visualizador, Operador, Admin, DEV)
- Backup e restauração do banco
- Monitoramento do sistema
- Changelog de versões completo

🔧 FUNCIONALIDADES TÉCNICAS
- Deploy automático com versionamento
- Sistema de logs completo
- API REST para integrações
- Design responsivo (mobile-first)
- Sistema de busca global
- Tema claro/escuro

REQUISITOS:
- Python 3.11+
- PostgreSQL (produção) ou SQLite (desenvolvimento)
- Navegador moderno (Chrome, Firefox, Safari, Edge)

DEPENDÊNCIAS PRINCIPAIS:
- Flask 2.3+ (framework web)
- SQLAlchemy 2.0+ (ORM)
- ReportLab (geração de PDFs)
- WeasyPrint (HTML para PDF)
- Matplotlib (gráficos)
- Pillow (processamento de imagens)
- QRCode (geração de códigos)
- Waitress (servidor WSGI)

INSTALAÇÃO:

1. CLONE DO REPOSITÓRIO:
   git clone https://github.com/SrLuther/MultiMax.git
   cd MultiMax

2. AMBIENTE VIRTUAL:
   python3 -m venv venv
   # Windows:
   venv\Scripts\activate
   # Linux/Mac:
   source venv/bin/activate

3. INSTALAÇÃO DE DEPENDÊNCIAS:
   pip install -r requirements.txt

4. CONFIGURAÇÃO DO BANCO:
   # Desenvolvimento (SQLite padrão):
   # Funciona automaticamente
   
   # Produção (PostgreSQL):
   export SQLALCHEMY_DATABASE_URI=postgresql://usuario:senha@host:5432/database

5. VARIÁVEIS DE AMBIENTE (OPCIONAL):
   export SENHA_ADMIN=sua_senha_admin
   export SENHA_OPERADOR=sua_senha_operador
   export FLASK_ENV=production
   export SECRET_KEY=sua_chave_secreta

6. EXECUÇÃO:
   # Desenvolvimento:
   python app.py
   
   # Produção:
   waitress-serve --host=0.0.0.0 --port=8000 app:app

DEPLOY E VERSIONAMENTO:
O sistema possui deploy automático com controle de versões:

1. NUNCA use `git push` diretamente
2. SEMPRE use os scripts de versionamento:
   - Windows: .\git-push-with-version.ps1
   - Linux/Mac: ./git-push-with-version.sh

3. O sistema automaticamente:
   - Incrementa versão (patch/minor/major)
   - Atualiza CHANGELOG.md
   - Cria tags Git
   - Faz push seguro

SERVICO SYSTEMD (para rodar como servico):
------------------------------------------
Crie o arquivo /etc/systemd/system/multimax.service:

[Unit]
Description=MultiMax App
After=network.target

[Service]
User=www-data
WorkingDirectory=/caminho/para/multimax
Environment="PATH=/caminho/para/multimax/venv/bin"
ExecStart=/caminho/para/multimax/venv/bin/python app.py
Restart=always

[Install]
WantedBy=multi-user.target

Depois execute:
sudo systemctl daemon-reload
sudo systemctl enable multimax
sudo systemctl start multimax
